### Organizational Unit (OU) Structure
#### Objective

To simulate a real business environment, Organizational Units were created for users, computers, servers and different departments. Each OU is assigned with Groups to assign user rights and permissions.

#### Step 1 - Open AD: Users and Computers
- Log into the Domain Controller
- Open the Start Menu
- Search and open Users and Computers

#### Step 2 - Create the OU
- Find the domain root (Top-level container)
- Right click on the Domain root
- Select New > Organizational unit
- Name the OU and select OK (Make sure Protect container from accidental deletion is checked)

#### Step 3 - Create Sub OUs 
- Right click on the branch
- Select New > Organizational unit
- Name the Sub OU and select OK (Make sure Protect container from accidental deletion is checked)

#### OU Structure

OU - USER, COMPUTER (Main OU)  
OU - TELCO, FINTECh (Sub OU)

### Create Users

#### Step 1 - Open AD Users and Computers
- Log into Domain Controller
- Open Active Directory Users and Computers
- Right click on the created OU (USER)
- Select New > User
- Add details such as logon name and password
- Set an initial password
- Uncheck User must change password at next logon (for this lab)
- Ensure User cannot change password is unchecked
- Ensure Password never expires is unchecked
- Select Next, then Finish
