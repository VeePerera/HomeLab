## Common Problems and Troubleshooting 

### Cannot see the Wi-Fi
#### Steps to troubleshoot
- Check Airplane mode is OFF for Wi-Fi is ON for Wi-Fi connection
- Run the built-in Network Troubleshooter (Settings > Network & Internet > Advanced network settings > Network troubleshooter)
- Check for adapter issues through Device manager> Network Adapters > Enable device or update driver
- Enable the Wi-Fi adapter through Control Panel > Network and Internet > Network connections
- 


### Wi-Fi connected but no internet
#### Steps to troubleshoot
- First check other devices can connect to the network to isolate the issue
- Run the built-in Network Troubleshooter (Settings > Network & Internet > Advanced network settings > Network troubleshooter)
- Release and renew IP: ```ipconfig /release``` then ```ipconfig /renew```
- Flush DNS cache: ```ipconfig /flushdns```
- Forget the network under Manage known networks, then reconnect and re-enter the password
- Update or roll back the Wi-Fi adapter driver via Device Manager
> [!CAUTION]
> If unresolved, perform a full Network Reset (last resort requires re-entering all saved Wi-Fi passwords)
