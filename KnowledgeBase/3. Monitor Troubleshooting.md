## Monitor Troubleshooting

### Monitor screen is black with no signal detected
#### Steps to troubleshoot
- Check Power
- Change the HDMI cable
- Check drivers for updates

### Set the Primary Display when multiple displays available
#### Steps to troubleshoot
- Go to This PC > Properties
- System > Display > Multiple Displays
- Select the Primary Display and make it as the Primary

### Mouse is not moving properly in multiple display environment
#### Steps to troubleshoot
- Go to This PC > Properties
- System > Display > Multiple Displays
- Arrange in through Display configuration - How it physically arranged

### Image on the screen appears to flash lines or colour inconsistency
#### Possible Causes
- Display not properly connected
- GPU overheating
- GPU faulty or malfunction

#### Steps to troubleshoot
- Dissemble the display to check connections
- Clean computer dust & debris
- Replace GPU

### Display in VGA Mode
#### Possible Causes
- Computer in Safe Mode
- Driver corrupted

#### Steps to troubleshoot
- Reboot
- Update/Install driver in Safe Mode
