## Common Problems and Troubleshooting

### Client cannot join the Domain
#### Possible Causes
- Client and Domain were in diiferent virtual Networks
- Client VM is not pointed to the Domain Controller
- Domain controller is unreachable
  
#### Steps to troubleshoot
- Check the client is connected to network
- Ping the domain
- Domain IP address must be assigned as the DNS address in client's machine - ```ipconfig /all```
- Delete the host from the AD and re-add
> [!NOTE]
> If all steps failed - Back up the client profile and re-image client machine

### Group Policy was not applied
#### Possible Causes
- Group Policy was not added to the relevant group
  
#### Steps to troubleshoot
- Isolate the issue to identify whether it is a policy issue or user specific issue
- Identify which group/groups user belong to - ```whoami /groups```
- Assign user to the relevant group
- Restart the client machine 

### Login fails after Domain join
#### Possible Causes
- The machine was not rebooted after joining the domain
- The user logged in with a local account
- The username format is incorrect

#### Steps to troubleshoot
- Check the client is connected to network
- Ping the domain
- Check DNS settings
- Verify correct domain name by login ```DOMAIN\username or email@domain.com```
- Verify the computer account exists in Active Directory 


## Real-World common Scenario 

John Doe locked out from his account after forgetting his password. As the system Admin, you were asked to unlock his account and reset his password and allow him to add a new password when he log in to the computer  

- John Doe is locked from his account after 3 unsucessful attempts (Lockout policy is set to 3 attempts)
