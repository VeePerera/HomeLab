## Backup Profile

### Method 1 - Through Backup & Restore
- Control Panel > Search Backup and Restore
- Click setup backup
- Select external driver/USB as the backup location and click Next
- Select what you want to backup - Select either _let Windows choose_ or _Let me choose_ 
- Uncheck _Include a system image_ if only backing up the profile.
